# Custom Caravans

A small companion mod for [pyalienlife](https://mods.factorio.com/mod/pyalienlife) that lets you paint
each individual caravan and caravan outpost with its own custom color, just like locomotives or train
stops - instead of every caravan/outpost of a given type looking identical.

## Features

- **Per-entity color** for all five caravan units (`caravan`, `fluidavan`, `flyavan`, `fluidflyavan`,
  `nukavan`), their five TURD tech-path variants (`*-turd`), and all four outpost buildings
  (`outpost`, `outpost-fluid`, `outpost-aerial`, `outpost-aerial-fluid`).
- A small color-picker panel opens alongside the entity's own GUI (the vanilla container/storage-tank
  GUI for outposts, pyalienlife's own caravan GUI for caravans), with preset swatches, R/G/B sliders,
  a live preview, and a reset button. Color changes apply immediately.
- **Settings copy/paste**: shift-right-click a colored caravan or outpost to copy its color, then
  shift-left-click any other caravan or outpost (any combination, including cross-type) to paste it.
- Outpost colors survive blueprinting (ghost ➜ build) and entity cloning.

## How it works

Caravans and caravan outposts don't support the engine's native per-entity `color` field (that's
limited to a handful of entity types like locomotives and characters), so this mod renders a tinted
overlay on top of each colored entity using `LuaRendering`:

- `caravan` and `fluidavan` (and their TURD variants) have a dedicated mask sprite layer in
  pyalienlife's graphics, so their overlay is a crisp, fully-opaque recolor of that mask, synced to
  the unit's current facing direction every few ticks. The baked-in static mask layer (yellow flags
  on caravan, blue on fluidavan) is stripped from the base sprite at data stage - otherwise it shows
  through beside the overlay whenever the walk-cycle phases drift apart ("double flags"). In exchange,
  these caravans always carry an overlay: uncolored ones get their original tint as the default, both
  when built and via a sweep when the mod is first added to an existing save.
- The four outposts use mask sprites shipped in this mod (`graphics/*-mask.png`, generated by
  `graphics/make_masks.py`): the livery accents of the base sprite (banner, pY logo, hazard stripes)
  isolated by hue into a grayscale paint region, so coloring an outpost repaints its livery crisply,
  locomotive-style.
- `flyavan`, `fluidflyavan`, and `nukavan` have no mask art, so their overlay is a translucent tinted
  "wash" built from their existing body sprite.

All prototype geometry for the overlays (sprite sheet layout, frame counts, shifts) is read from
pyalienlife's own prototypes at data-stage load time rather than hardcoded, so the mod stays in sync
with pyalienlife's graphics as long as the underlying sheets don't change shape.

## Compatibility

Requires `pyalienlife >= 3.0.66` on Factorio `2.0`. No other dependencies. No pyalienlife files are
modified on disk - only prototype fields are patched at load time (`additional_pastable_entities`,
plus new overlay animation/sprite prototypes), and everything else is plain `script.on_event` logic.

## Known limitations

- The overlay's walk-cycle frame is not phase-locked to the caravan's own animation frame (the engine
  doesn't expose that), so a moving caravan's overlay may drift slightly out of sync with the body
  sprite. This mostly affects the area the mask/wash covers and is expected to be visually tolerable.
- Caravans themselves aren't blueprintable in pyalienlife (they're placed via an item-with-tags and
  mined back into one), so color persistence through mining/placing a caravan is not implemented in
  this version - only outposts persist color through blueprints.
