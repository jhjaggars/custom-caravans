# Custom Caravans

A small companion mod for [pyalienlife](https://mods.factorio.com/mod/pyalienlife) that lets you paint
each individual caravan and caravan outpost with its own custom color, just like locomotives or train
stops - instead of every caravan/outpost of a given type looking identical.

## Features

- **Per-entity color** for all five caravan units (`caravan`, `fluidavan`, `flyavan`, `fluidflyavan`,
  `nukavan`), their five TURD tech-path variants (`*-turd`), and all four outpost buildings
  (`outpost`, `outpost-fluid`, `outpost-aerial`, `outpost-aerial-fluid`).
- A small color-picker panel opens alongside the entity's own GUI (the vanilla container/storage-tank
  GUI for outposts, pyalienlife's own caravan GUI for caravans), with preset swatches, R/G/B sliders,
  a live preview, and a reset button. Color changes apply immediately.
- **Settings copy/paste**: shift-right-click a colored caravan or outpost to copy its color, then
  shift-left-click any other caravan or outpost (any combination, including cross-type) to paste it.
- Outpost colors survive blueprinting (ghost ➜ build) and entity cloning.

## How it works

Caravans and caravan outposts don't support the engine's native per-entity `color` field (that's
limited to a handful of entity types like locomotives and characters), so this mod renders a tinted
overlay on top of each colored entity using `LuaRendering`:

- **Outposts** are repainted directly: the mod ships a livery mask per outpost
  (`graphics/*-mask.png`, generated by `graphics/make_masks.py`), which isolates the banner, pY logo
  and hazard stripes of the base sprite by hue into a grayscale paint region. Tinting that mask
  repaints the livery crisply, exactly like a locomotive. Outposts are stationary single-sprite
  entities, so the overlay simply lines up. Mask geometry is derived from pyalienlife's own prototype
  at load time rather than hardcoded, so it stays in sync with their graphics.
- **Caravans** get a colored ring on the ground instead (`graphics/caravan-marker.png`, generated by
  `graphics/make_marker.py`), and keep their own stock livery untouched. A caravan's walk cycle
  advances about one frame per tick (`distance_per_frame` 0.13 against `movement_speed` 0.14) and the
  engine never exposes an entity's current animation frame, so a tinted copy of the body mask cannot
  be held in phase with the sprite - it visibly detaches the moment the caravan moves. A
  position-locked marker has no phase to get wrong, and reads at a glance whether the caravan is
  parked or in transit.

## Compatibility

Requires `pyalienlife >= 3.0.66` on Factorio `2.0`. No other dependencies. No pyalienlife files are
modified on disk - only prototype fields are patched at load time (`additional_pastable_entities`
and the `get-by-unit-number` flag), plus new sprite prototypes; everything else is plain
`script.on_event` logic. There are no per-tick handlers: script renderings follow their target
entity on their own.

## Known limitations

- Caravans show their color as a ground marker rather than a repainted body, for the animation-phase
  reason described above.
- Caravans themselves aren't blueprintable in pyalienlife (they're placed via an item-with-tags and
  mined back into one), so color persistence through mining/placing a caravan is not implemented in
  this version - only outposts persist color through blueprints.
